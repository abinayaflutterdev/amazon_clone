# Flutter Amazon Clone

## About the Project

This is an Amazon-inspired shopping application developed using Flutter and Dart. It recreates the shopping app experience with a user-friendly interface and reusable UI components.

## Features

- Amazon-inspired shopping interface
- Display products with images and details
- Browse products in a shopping-style layout
- Responsive user interface
- Reusable custom widgets

## Technologies Used

- Flutter
- Dart

## Concepts Learned

- Stateless and Stateful Widgets
- Widget composition
- Reusable Custom Widgets
- Constructors and parameter passing
- Layouts using Row, Column, and Container
- Navigation between screens
- Responsive UI design

## Project Structure

- `lib/` – Contains the main application source code and screens.
- `assets/` – Stores images and other application assets, if used.
- `pubspec.yaml` – Defines project dependencies and asset configuration.

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Android Studio or VS Code.
3. Run `flutter pub get` to install dependencies.
4. Run `flutter run` to launch the application.
